To check the given Array is empty or not :

const arr = []

if(arr.length === 0) {
    console.log("Array is empty)
}


To check the given object is empty or not :

const newObj = {}

if((Object.keys(newObj)).length === 0){
    console.log("Object is empty)
}

Note : 
* Object.keys(object_name) ===> it returns a new array containing all the keys in that object
* So we can use .length property of array to Object.keys(newObj)
